## Review Structure

Each review includes:
- `id`: Unique identifier (language-tour-number format)
- `tour_slug`: Specific tour identifier
- `language`: Language code (en, de, fr, es, ar)
- `author`: Authentic name for language/culture
- `author_location`: Realistic location for language
- `rating`: 1-5 stars (weighted toward 4-5)
- `review_date`: Date within last 6 months
- `title`: Compelling review title
- `content`: Detailed, tour-specific review content
- `verified`: true (all reviews verified)
- `experience_type`: Categorized experience
- `helpful_count`: Realistic helpfulness votes
