# Story 1.12: Process Payment & Finalize Booking

## Goal
Enable guests to securely pay for their booking and finalize the reservation, completing the end-to-end booking flow.

## Why
- Converts guest interest into revenue.
- Ensures bookings are only confirmed after successful payment.
- Provides a seamless, trustworthy checkout experience.

## What
- Integrate a payment provider (e.g., Stripe) for secure guest payments.
- Add a payment step to the guest checkout flow.
- Update booking status to "confirmed" after successful payment.
- Send booking confirmation to the guest (email or on-screen).
- Restrict access to payment and confirmation to the booking guest.
- Add error handling for payment failures.

### Success Criteria
- [ ] Guests can pay for their booking using a secure payment provider.
- [ ] Bookings are only confirmed after successful payment.
- [ ] Guests receive a booking confirmation after payment.
- [ ] Booking status is updated in the database.
- [ ] Payment errors are handled gracefully.
- [ ] UI matches design guidelines and is responsive.

### Per task pseudocode
```tsx
// Task 1: Payment handler
const handlePayment = async (bookingId, paymentDetails) => {
  setLoading(true)
  const res = await fetch(`/api/pay`, {
    method: "POST",
    body: JSON.stringify({ bookingId, paymentDetails }),
    headers: { "Content-Type": "application/json" }
  })
  if (res.ok) {
    // Redirect to confirmation
    window.location.href = `/booking/confirmed/${bookingId}`
  } else {
    showToast("Payment failed", "error")
  }
  setLoading(false)
}
```
