# Story 1.5: Admin UI – Edit Tour

## Goal
Enable admin users to edit existing tours via the admin dashboard, providing a form pre-filled with current tour data, robust validation, and seamless integration with the backend API.

## Why
- Allows staff to correct or update tour information as needed.
- Ensures data accuracy and up-to-date offerings.
- Completes the CRUD cycle for tour management.

## What
- Add an "Edit" action to the admin tours list.
- Implement an "Edit Tour" page/component with a form pre-filled with the selected tour's data.
- Include all editable fields: title, description, price, category, duration, image, and availability.
- Implement client-side validation for all fields.
- Integrate with the backend API (e.g., PUT or PATCH /api/admin/tours/[tourId]).
- Display success and error messages to the user.
- Restrict access to authenticated admin users only.
- Add loading and error states for API calls.

### Success Criteria
- [x] "Edit Tour" form is accessible from the admin dashboard.
- [x] All fields are pre-filled and validated on the client.
- [x] Form submits updated data to the backend and handles responses.
- [x] Only authenticated admins can access the form.
- [x] User receives clear feedback on success or failure.
- [x] UI matches design guidelines and is responsive.

```tsx
  <Input {...register("title", { required: true })} defaultValue={tour.title} />
  <Textarea {...register("description", { required: true })} defaultValue={tour.description} />
  <Input type="number" {...register("price", { required: true, min: 0 })} defaultValue={tour.price} />
  <Input {...register("category", { required: true })} defaultValue={tour.category} />
  <Input type="number" {...register("duration_days", { required: true, min: 1 })} defaultValue={tour.duration_days} />
  <Input type="file" {...register("image")} />
  <Button type="submit" disabled={isSubmitting}>Update Tour</Button>
</form>
```

### Per task pseudocode
```tsx
// Task 2: Form submission handler
const onSubmit = async (data) => {
  setLoading(true)
  const res = await fetch(`/api/admin/tours/${tour.id}`, {
    method: "PUT",
    body: JSON.stringify(data),
    headers: { "Content-Type": "application/json" }
  })
  if (res.ok) {
    showToast("Tour updated successfully")
    router.push("/admin/tours")
  } else {
    showToast("Failed to update tour", "error")
  }
  setLoading(false)
}
```
