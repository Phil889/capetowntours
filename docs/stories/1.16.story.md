# Story 1.16: Admin Management of Custom/Private Bookings

## Goal
Enable admins to view, manage, and fulfill custom/private tour bookings created by users through the custom privat tour planner.

## Why
- Ensures operational visibility and control over custom/private bookings.
- Allows admins to update booking status, contact customers, and coordinate fulfillment.
- Supports customer service and business process needs.

## What
- Add an admin dashboard view for custom/private bookings.
- Display key details: customer info, itinerary, dates, status.
- Allow admins to update booking status (e.g., pending, confirmed, completed, cancelled).
- Provide a way to contact the customer (e.g., email link).
- Add search/filter for bookings by date, status, or customer.

### Success Criteria
- [ ] Admins can view a list of all custom/private bookings.
- [ ] Each booking shows itinerary, customer info, and status.
- [ ] Admins can update the status of a booking.
- [ ] Admins can contact the customer from the dashboard.
- [ ] Bookings can be searched/filtered by key fields.
