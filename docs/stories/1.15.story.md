# Story 1.15: Integrate Custom Privat Tour Planner into User Flow

## Goal
Integrate the CustomTourPlanner component into the user-facing site, enabling real users to build, review, and submit custom private tour itineraries.

## Why
- Makes the custom tour planner feature accessible to users.
- Enables end-to-end testing and validation of the booking flow.
- Provides a seamless, interactive experience for building private tours.

## What
- Add the CustomTourPlanner component to a public page (e.g., /custom-tour or /tours).
- Fetch available tours from the backend and pass them as props to the planner.
- Wire up the "Proceed to Booking" button to submit the itinerary to /api/book/custom.
- Display user feedback on success or error.
- Add Playwright tests for the custom booking flow.

### Success Criteria
- [ ] Users can access the custom tour planner from the main site navigation.
- [ ] Available tours are loaded dynamically and displayed in the planner.
- [ ] Users can build and submit a custom itinerary, which is stored in Supabase.
- [ ] Users receive clear feedback on booking success or failure.
- [ ] Playwright tests cover the full custom booking flow.
