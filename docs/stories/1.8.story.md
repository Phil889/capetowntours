# Story 1.8: Admin UI – Export Bookings and Reports

## Goal
Enable admin users to export bookings data and generate reports (e.g., CSV, PDF) from the admin dashboard.

## Why
- Allows staff to analyze booking trends and operational data.
- Supports business reporting, accounting, and external data sharing.
- Improves operational efficiency by providing downloadable data.

## What
- Add "Export" functionality to the admin dashboard for bookings.
- Allow admins to export bookings data for a selected date range, tour, or status.
- Support export formats: CSV (minimum), PDF (optional).
- Provide clear feedback on export success or failure.
- Restrict access to authenticated admin users only.
- Ensure exported data matches filters applied in the UI.

### Success Criteria
- [ ] Admins can export bookings data from the dashboard.
- [ ] Exported data matches selected filters (date range, tour, status).
- [ ] CSV export is available; PDF export is optional.
- [ ] Only authenticated admins can access the feature.
- [ ] User receives clear feedback on export actions.
- [ ] UI matches design guidelines and is responsive.

**Status:** Story drafted and ready for implementation.

### Per task pseudocode
```tsx
// Task 2: Export handler
const handleExport = async (filters) => {
  setLoading(true)
  const res = await fetch(`/api/admin/bookings/export?${new URLSearchParams(filters)}`)
  if (res.ok) {
    const blob = await res.blob()
    downloadFile(blob, "bookings.csv")
    showToast("Export successful")
  } else {
    showToast("Export failed", "error")
  }
  setLoading(false)
}
```
