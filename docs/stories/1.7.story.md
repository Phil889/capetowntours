# Story 1.7: Admin UI – View and Manage Bookings

## Goal
Enable admin users to view, filter, and manage bookings for all tours through the admin dashboard.

## Why
- Provides staff with visibility into all bookings for operational oversight.
- Allows admins to manage bookings (e.g., confirm, cancel, or update status).
- Supports customer service and operational efficiency.

## What
- Design and implement a "Bookings" management UI in the admin dashboard.
- Display a list/table of all bookings with key details (tour, customer, date, status, etc.).
- Allow filtering/searching by tour, date, customer, and booking status.
- Provide actions to confirm, cancel, or update booking status.
- Integrate with the backend to fetch and update booking data.
- Restrict access to authenticated admin users only.
- Add loading and error states for API calls.

### Success Criteria
- [ ] Admins can access the "Manage Bookings" UI from the dashboard.
- [ ] Admins can view all bookings with relevant details.
- [ ] Admins can filter/search bookings by key fields.
- [ ] Admins can update booking status (confirm, cancel, etc.).
- [ ] Changes are saved to the backend and reflected in the UI.
- [ ] Only authenticated admins can access the feature.
- [ ] User receives clear feedback on success or failure.
- [ ] UI matches design guidelines and is responsive.

**Status:** Implemented and validated. Public tour detail page is live.

// Task 2: Update booking status handler
const updateBookingStatus = async (bookingId, status) => {
  setLoading(true)
  const res = await fetch(`/api/admin/bookings/${bookingId}`, {
    method: "PATCH",
    body: JSON.stringify({ status }),
    headers: { "Content-Type": "application/json" }
  })
  if (res.ok) {
    showToast("Booking status updated")
  } else {
    showToast("Failed to update booking", "error")
  }
  setLoading(false)
