# Story 1.9: Admin UI – Manage Users

## Goal
Enable admin users to view, search, and manage user accounts through the admin dashboard.

## Why
- Provides staff with visibility into all registered users for support and operational oversight.
- Allows admins to manage user status (e.g., activate, deactivate, reset password).
- Supports customer service and security.

## What
- Add a "Users" management UI to the admin dashboard.
- Display a list/table of all users with key details (email, status, created_at, etc.).
- Allow filtering/searching by email, status, and registration date.
- Provide actions to activate/deactivate users and reset passwords.
- Integrate with the backend to fetch and update user data.
- Restrict access to authenticated admin users only.
- Add loading and error states for API calls.

### Success Criteria
- [ ] Admins can access the "Manage Users" UI from the dashboard.
- [ ] Admins can view all users with relevant details.
- [ ] Admins can filter/search users by key fields.
- [ ] Admins can activate/deactivate users and reset passwords.
- [ ] Changes are saved to the backend and reflected in the UI.
- [ ] Only authenticated admins can access the feature.
- [ ] User receives clear feedback on success or failure.
- [ ] UI matches design guidelines and is responsive.

**Status:** Story drafted and ready for implementation.
