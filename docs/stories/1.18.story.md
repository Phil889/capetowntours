# Story 1.18: Advanced Itinerary Validation & Availability Checks for Custom Privat Tour Planner

## Goal
Ensure that custom/private itineraries are valid, conflict-free, and only include tours with available slots, providing real-time feedback to users during booking.

## Why
- Prevents double-booking and scheduling conflicts.
- Improves user trust and satisfaction by ensuring only available tours can be booked.
- Reduces admin intervention and booking errors.

## What
- Validate that selected tours in a custom itinerary do not overlap in date/time.
- Check real-time availability for each tour and date before allowing booking.
- Provide user feedback if a tour is unavailable or if there is a conflict.
- Prevent submission of invalid or conflicting itineraries.
- Notify admins of failed or problematic booking attempts.

### Success Criteria
- [ ] Users cannot book tours that are unavailable or already fully booked.
- [ ] Users receive clear feedback if there is a conflict or availability issue.
- [ ] The system prevents submission of invalid itineraries.
- [ ] Admins are notified of failed or problematic booking attempts.
