# Story 1.4: Admin UI – Create Tour Form

## Goal
Develop the admin-facing UI to allow authorized users to create new tours via a form, integrating with the backend API and ensuring robust validation and user feedback.

## Why
- Enables admin users to add new tours through a user-friendly interface.
- Completes the end-to-end workflow for tour management.
- Ensures data integrity and a smooth admin experience.

## What
- Design and implement a "Create Tour" form in the admin dashboard.
- Include all required fields: title, description, price, category, duration, image upload, and availability.
- Implement client-side validation for all fields.
- Integrate with the POST `/api/admin/tours` endpoint.
- Display success and error messages to the user.
- Restrict access to authenticated admin users only.
- Add loading and error states for API calls.

### Success Criteria
- [x] "Create Tour" form is accessible from the admin dashboard.
- [x] All required fields are present and validated on the client.
- [x] Form submits data to the backend and handles responses.
- [x] Only authenticated admins can access the form.
- [x] User receives clear feedback on success or failure.
- [x] UI matches design guidelines and is responsive.

### UI Structure
```tsx
// Example: Create Tour Form (React, Next.js, shadcn/ui)
<form onSubmit={handleSubmit(onSubmit)}>
  <Input {...register("title", { required: true })} placeholder="Title" />
  <Textarea {...register("description", { required: true })} placeholder="Description" />
  <Input type="number" {...register("price", { required: true, min: 0 })} placeholder="Price" />
  <Input {...register("category", { required: true })} placeholder="Category" />
  <Input type="number" {...register("duration_days", { required: true, min: 1 })} placeholder="Duration (days)" />
  <Input type="file" {...register("image")} />
  <Button type="submit" disabled={isSubmitting}>Create Tour</Button>
</form>
```

### Per task pseudocode
```tsx
// Task 2: Form submission handler
const onSubmit = async (data) => {
  setLoading(true)
  const res = await fetch("/api/admin/tours", {
    method: "POST",
    body: JSON.stringify(data),
    headers: { "Content-Type": "application/json" }
  })
  if (res.ok) {
    showToast("Tour created successfully")
    reset()
  } else {
    showToast("Failed to create tour", "error")
  }
  setLoading(false)
}
```
