# Story 1.20: User & Admin Notifications for Custom Privat Tour Planner

## Goal
Implement a notification system to keep users and admins informed about important events related to custom/private bookings, such as status changes, itinerary updates, and payment confirmations.

## Why
- Improves communication and transparency for both users and admins.
- Reduces missed updates and manual follow-ups.
- Enhances user trust and satisfaction.

## What
- Notify users via email when their itinerary is updated, cancelled, or confirmed by admin.
- Notify admins via email or dashboard when a new custom/private booking is submitted, paid, or changed.
- Provide clear, branded notification templates for all events.
- Allow users to opt in/out of certain notifications.

### Success Criteria
- [ ] Users receive timely notifications for all key booking events.
- [ ] Admins are notified of new, paid, or changed custom/private bookings.
- [ ] Notification emails use consistent capetownsafari.tours branding.
- [ ] Users can manage notification preferences.
